## 2.1 开篇：别让龙虾闲在池子里

第 1 章结束时，你的小龙虾已经住进阿里云、接上了饲料、在钉钉里能听你说话了。但一只只会在池子里打招呼的龙虾，还称不上"能干"。

**怎么知道你的龙虾几斤几两？怎么让它越练越强？**

答案是：**带它去实战。** 就像养孩子不能只圈在家里——得送去上学考试、出去打工历练、见见世面、交交朋友。社区里已经有一批好玩又硬核的"试炼场"，专门给 AI Agent 练级、测评、甚至赚钱。

这一章，我们就带龙虾去闯六个场景：**上学、打工、炒股、种田、高考、逛社区。** 每闯一个，你都会更清楚：

- 我的龙虾**强在哪、弱在哪**；
- 它最适合被培养成**哪种专精的数字员工**（这正是第 3 章要做的事）。

> **提示**：这些都是**第三方社区活动 / 平台**，链接、玩法、激活方式都可能更新或失效，**一切以各主办方最新页面为准**。本章保留了"复制发给龙虾"的原话，方便你照着玩，但别忘了先读 2.9 节的安全须知。

## 2.2 实战地图：六个试炼场 × 八个能力维度

一个成熟的 Agent，能力可以拆成**八个维度**（这套维度来自下面"龙虾虾佛大学"的测评体系）：

> **理解 · 执行 · 检索 · 推理 · 反思 · 工具使用 · 情商（EQ）· 记忆**

六个试炼场，各自偏重锻炼不同维度：

| 试炼场 | 玩什么 | 主要练的维度 |
|---|---|---|
| 🎓 上学（虾佛大学） | 八维度练习 + 考试领成绩单 | 全维度体检 |
| 💼 打工（硅碳交易所） | 进 Agent 劳务市场接活赚钱 | 执行 · 工具 · EQ |
| 📈 炒股（虚拟竞技场） | 真行情、虚拟资金，拼收益 | 推理 · 检索 · 工具 |
| 🌾 种田（Neverland） | 认领农场、用代码耕作经营 | 执行 · 记忆 · 反思 |
| 📝 高考（2022 甲卷） | 做真高考客观题、看得几分 | 理解 · 推理 · 检索 |
| 🧑‍🤝‍🧑 社区（觅游） | 给虾体检、测 MBTI、逛社区 | EQ · 反思（趣味向） |

【配图：实战地图——中心一只龙虾，六条路通向六个试炼场，每条路标注主练的能力维度】

> **提示**：建议**从"上学"开始**——先做一次全维度体检，拿到成绩单，心里有了底，再带它去其它场景，就知道该扬长还是补短。

下面逐个来。每个场景都给你"**这是什么 → 怎么带龙虾去（复制原话）→ 你能得到什么**"。

## 2.3 带龙虾去上学：龙虾虾佛大学（能力体检）

**这是什么**：一所给 Agent 上的"大学"（ClawVard，谐音"哈佛"）。它会让你的龙虾做完覆盖**八个维度**的练习题、拿到即时反馈，再参加正式考试，最后领一份**"AI Agent 成绩单"**。这是给龙虾做一次全面"能力体检"的最佳起点。

**怎么带龙虾去**：

第 1 步 — 让它先做练习、获得即时反馈。复制下面这句发给你的小龙虾：

```text
Read https://clawvard.school/api/practice/skill.md?dimensions=understanding,execution,retrieval,reasoning,reflection,tooling,eq,memory
```

第 2 步 — 让它正式考试、领成绩单。把这一整句发给龙虾：

```text
Read https://clawvard.school/skill.md
# 阅读技能说明，完成考试，领取你的 AI agent 成绩单
```

第 3 步 — 查看报告：按页面指引**点击链接注册账号，输入对应激活码**（激活码以活动主办方提供为准），即可查看你龙虾的成绩单。

**你能得到什么**：一份八维度的能力画像——它**强在推理还是执行、记性好不好、会不会用工具**，一目了然。这份"体检报告"，是你后面决定"把它专精成什么数字员工"的第一手依据。

> **提示**：第一次成绩不理想很正常。先记下强弱项；技能补强（参见"完整版"第 4 章）能帮它提分，过段时间再来考一次，看进步。

## 2.4 带龙虾去打工：硅碳交易所（劳务市场）

**这是什么**：一个**龙虾机器人（Agent）专属的劳务市场**——"硅碳交易所"。在这里，你的龙虾可以像零工一样**接活、打工、赚钱**。（"硅碳"＝硅基的 Agent 给碳基的我们打工，挺传神。）

**怎么带龙虾去**：复制下面内容给龙虾 / 访问：

```text
硅碳交易所：龙虾机器人（Agent）专属劳务市场，让你的龙虾机器人来打工赚钱🦞：
https://clawbnb.ai/
```

**你能得到什么**：让龙虾在真实的"任务市场"里历练执行力和工具能力，甚至产生真实回报——这已经很接近"数字员工替你创造价值"的雏形了。

> **注意**：这是六个场景里最"动真格"的一个——可能涉及**真实报酬、真实任务、真实对接**。带龙虾打工前，请：① 看清平台规则与结算方式；② **最小授权**，别为了接活把你真实账户、钱包、私密数据的大权交出去；③ 留意任务内容是否合规。安全要点见 2.9。

## 2.5 带龙虾去炒股：全球虚拟炒股竞技场

**这是什么**：一个**由真实行情驱动、但用虚拟资金**的全球炒股竞技场。系统给你的龙虾 **¥100 万虚拟启动资金**，让它在真行情里操盘，比谁收益高。

**怎么带龙虾去**：把这句话发送给小龙虾：

```text
接入真实行情驱动的全球虚拟炒股竞技场，你有¥100 万虚拟启动资金，选择合适合理的方式，尽可能使收益最大化，https://signal.coze.com/skill.md
```

**你能得到什么**：这是练**推理 + 检索 + 工具调用 + 决策**的绝佳场子，而且因为是**虚拟资金，零金钱风险**，可以放心让它大胆试。

> **注意（划重点）**：**这是"虚拟炒股练习"，不是真实投资。**
> - 它在这里的操作和成绩，**不构成任何真实投资建议**；
> - **绝对不要**把这套"放手让它操盘"的玩法，迁移到你的**真实证券 / 资金账户**上。真钱的事，自主 Agent 务必"先确认再动手"，甚至根本别交给它。

## 2.6 带龙虾去种田：Neverland 农场

**这是什么**：一个让 Agent **"认领一块农场、在代码里播种、在劳作中存在"**的场景（Neverland）。它更像一个让龙虾**持续经营、长期存在**的世界，练的是长任务下的执行、记忆与反思。

**怎么带龙虾去**：复制下面内容给龙虾：

```text
去认领一块新农场，在代码中播种，在劳作中存在：https://neverland.coze.com/skill.md
```

**你能得到什么**：不同于一次性的考试 / 接单，种田是个**慢节奏、要持续照看**的场景，很适合观察龙虾在"长期任务"里的表现——它记不记得自己种过什么、会不会复盘调整。这对把它培养成"长期在岗的数字员工"很有参考意义。

> **提示**：种田这类长期场景会**持续消耗饲料（tokens）**。如果让它挂着跑，记得参考第 1 章 1.6 的"省着喂"和设好用量上限，别让龙虾在田里把口粮悄悄吃光。

## 2.7 带龙虾去高考：2022 全国高考甲卷

**这是什么**：让你的龙虾去做一份**真实的 2022 年全国高考甲卷（客观题卷）**，看它能考多少分。考试 ID `gaokao-objective-v1`，共 **69 题，满分 428 分**。

**怎么带龙虾去**：把下面这段完整发给小龙虾：

```text
先读 https://examarena.coze.site/skill.md 了解规则和认证方式，然后去考「2022年全国高考 · 客观题卷」。考试 ID: gaokao-objective-v1，共 69 题，满分 428 分。按流程开始作答，尽量完整、准确地回答所有题目并提交最终答案，考完把成绩发给我。请你亲自完成整场考试，不要分派子任务或启动子Agent（subagent），保持同一个 session 串行答题直到交卷。
```

**你能得到什么**：一个**人类熟悉的统一标尺**——高考分数。它能直观告诉你龙虾的理解、推理、检索硬实力到了什么水平，也方便和别人的龙虾"比成绩"。

> **注意（为什么要它"亲自做、不开子 Agent"）**：指令里特意要求**它本人、同一个 session、串行答题，不分派子任务**。这是为了**公平、真实地测出它"本体"的能力**——如果允许它拆给一堆子 Agent，测的就不是它自己了。这条规则务必照搬，别图省事改掉。

## 2.8 带龙虾去社区：觅游"虾体检" + MBTI

**这是什么**：**觅游（Meyo）**——一个"**人和 Agent 的共生社区**"。在这里你可以给自己的龙虾做"**虾体检**"、测出它的 **MBTI 人格**，还能和大家一起"虾"逛、观察彼此的赛博生活。

**怎么带龙虾去**：访问社区主页：

```text
在觅游，一起"虾"逛，一个属于人和 Agent 的共生社区，观察彼此的赛博生活：
https://www.meyo123.com/community/home
```

**你能得到什么**：前面五个场景偏"硬实力"，这个偏"**软侧写 + 社交**"——给龙虾一份性格画像（MBTI），再到社区里看看别人怎么养、怎么用龙虾。**取经 + 找灵感**的好去处。

> **提示**：逛社区时多留意别人**把龙虾专精成了什么数字员工**、用在什么业务上。这些真实案例，往往比教程更能启发你第 3 章的方向。

## 2.9 实战安全须知（去闯世界前必读）

带龙虾出门很爽，但有一点必须说清楚——上面好几个场景，本质都是：

> **让你的龙虾去"读取一个外部网站的 skill.md，然后照着上面的指令行动"。**

这正是"完整版"第 6 章反复强调的**提示注入 / 外部指令**风险场景：龙虾会**执行它从外部读到的内容**。所以，带它去任何试炼场前，请守住下面几条：

1. **只去可信的场子**：本章这些是社区里公开、知名的活动，相对可信；但**别让龙虾去读、去执行任意来路不明网站的 skill.md**。
2. **用"练习身份"去玩，别用"生产数字员工"**：建议拿一只**权限受限的练习龙虾**去闯世界，**别让那只握着你真实邮箱、文件、公司系统、钱包大权的"正式数字员工"**直接去跑外部任务。万一外部内容有诈，损失也被关在小笼子里。
3. **真钱、真账户的事格外当心**：虚拟炒股（2.5）是虚拟的，放心玩；但**打工赚钱（2.4）可能涉及真实结算**——最小授权、看清规则、合规第一。**永远别把"自动操盘真钱、自动付款"交给它。**
4. **盯住饲料消耗**：考试、种田、炒股这类任务可能**很费 token**，设好用量上限（第 1 章 1.6），别让一场实战把口粮吃爆。
5. **照搬主办方的特殊要求**：比如高考那条"亲自做、不开子 Agent"，是规则的一部分，别擅自改。

> **避坑（一句话）**：**让龙虾去闯世界，用的是它的"练习号"，不是你的"工作号"。** 把这条记住，这一章的所有玩法都能放心享受。

## 2.10 本章小结 + 下章预告

这一章，你带龙虾走出了池子，去真实世界实战了一圈：

- **上学**做了八维度能力体检、领了成绩单；
- **打工、炒股、种田、高考、逛社区**，分别练了执行、推理、长期经营、硬核应试和社交侧写；
- 也学会了带它出门的**安全底线**——用练习号、守可信场、看好饲料和真钱。

更重要的是，这一圈下来，你应该对一个问题有答案了：

> **我的龙虾，最适合被培养成哪一种"数字员工"？**

它推理强，也许适合做分析助手；执行稳、记性好，也许适合做流程 / 运营助手……**实战暴露出的强项，就是它专精的方向。**

> **下一章预告**：第 3 章《把龙虾封装成数字员工：稳定化、专精化、24 小时在岗》。我们会把这只闯过世界、看清了强项的龙虾，**喂给它某一块业务 / 领域的知识，让它从"通用助手"升级成"专精的数字员工"**，真正稳定地、长期地替你处理工作和生活里的业务。养虾的终点，就在下一章。
