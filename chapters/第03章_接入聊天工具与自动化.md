## 3.1 开篇：从"守着电脑"到"随时随地一句话"

前两章，你大概都是坐在电脑前，对着小龙虾的操作界面敲指令。这没问题，但有个隐形的天花板：**你必须在电脑前，它才能为你干活。**

可现实里，你想用它的时刻，往往恰恰不在电脑前——

- 在地铁上突然想起："让它把今天的日报先草拟好。"
- 周末出门玩，想起家里电脑还开着："顺手让它把上周的发票归个档。"
- 半夜睡了，希望早上 8 点自动收到一份资讯简报。

这一章，我们就拆掉这块天花板。做完之后，你的小龙虾会变成：**一个住在你电脑（或云服务器）里、你用微信 / Telegram 发条消息就能遥控、甚至到点自己醒来干活的"远程自动助理"。**

养龙虾的最后一步，是把它"放养"。

> **提示**：本章能力建立在第 1 章（装好本体、接好大脑）和第 2 章（装好基础技能、会派活）之上。如果前两章还没跑通，建议先回去补上再来。

## 3.2 接入总览：它能接哪些聊天工具，你该选哪个

小龙虾好用，一大半在于它**不挑入口**——你日常用哪个聊天工具，就用哪个指挥它。先看一张"选入口"表：

| 聊天入口 | 适合谁 | 特点 |
|---|---|---|
| Telegram | 海外 / 技术友好用户 | 机器人（Bot）生态成熟，接入文档多 |
| Discord | 社群 / 团队玩家 | 适合多人共用一只龙虾 |
| Slack | 职场 / 团队 | 和办公流程贴合 |
| WhatsApp / iMessage | 海外个人 | 日常即时通讯顺手 |
| 微信（QClaw） | 国内用户 | 经腾讯封装版 QClaw 绑微信遥控，最贴合国内习惯 |

（具体支持范围与接入方式以官方 / 对应封装版最新文档为准。）

怎么选？三句话：

- **国内用户**：直接上微信版 QClaw，体验最顺。
- **海外或爱折腾**：Telegram 是性价比最高的入门选择。
- **团队共用**：考虑 Discord / Slack。

> **注意**：把龙虾接到聊天工具，等于给它开了一扇"远程门"。门越多越方便，但每扇门都是一个潜在入口。建议**先只接一个你最常用的**，熟练并设好安全（见 3.6 节）后，再考虑加第二个。

## 3.3 手把手接入（示范：Telegram 与 微信 QClaw）

下面挑两个最有代表性的示范：海外首选 **Telegram**、国内首选 **微信 QClaw**。所有带 `<...>` 的都是占位符，真实命令 / 步骤以官方文档为准——请勿照抄占位符，勿执行非官方来源的命令。

### 3.3.1 接入 Telegram（海外首选）

大致四步（具体以官方文档为准）：

1. **创建一个 Telegram 机器人**：在 Telegram 里找到官方的 **BotFather**，按引导新建一个 Bot，拿到一串 **Bot Token**（形如 `<一串数字:一串字母>`）。
2. **把 Token 填给小龙虾**：在小龙虾的配置里填入这个 Bot Token（字段名以官方为准）。**示例结构**（仅示意，勿照抄）：
   ```json
   {
     "messaging": {
       "telegram": { "botToken": "<你的 Bot Token>" }
     }
   }
   ```
3. **重启 / 重载小龙虾**，让配置生效。
4. **绑定你自己**：给你的 Bot 发第一条消息，按官方指引完成"**只允许你本人遥控**"的身份绑定。

【配图：Telegram 里与小龙虾 Bot 的首段对话——你发"在吗"，它回"在，请下达任务"的截图】

> **避坑**：Bot Token 和 API Key 一样是钥匙，别截图发群、别提交到公开仓库。一旦泄露，立刻在 BotFather 里吊销重置。

> **注意**：务必完成"仅本人可遥控"的绑定。否则任何知道你 Bot 名字的人都可能给它发指令——而它是会动手的。

### 3.3.2 接入微信 QClaw（国内首选）

QClaw 是腾讯对 OpenClaw 体系的封装版，主打"绑微信、远程操控电脑"，省去手动配环境的麻烦。大致流程（以 QClaw 官方文档为准）：

1. 按 QClaw 官方指引安装 / 部署 QClaw（`<安装方式以官方为准>`）。
2. 用微信扫码 / 授权，完成账号绑定。
3. 绑定成功后，你在微信对话框里发消息，就能指挥它干活、收它的执行结果。

【配图：微信里给 QClaw 派任务、它回复执行结果的对话截图】

> **提示**：QClaw 是第三方封装产品，它的更新节奏、功能边界、隐私政策都以**它自己的官方说明**为准，与原版 OpenClaw 可能略有差异。涉及账号与隐私授权时，请认真阅读其条款。

### 3.3.3 验证接入是否成功

无论接哪个，验证方法一样——**发一句简单任务，看它在手机上回不回**：

```text
你好，报一下你现在的状态，并告诉我你能在我手机上帮我做哪些事。
```

能正常一来一回，就说明"嘴巴和耳朵"接通了。

## 3.4 远程操控：人在外面，怎么安全地遥控家里的龙虾

接通聊天工具后，你就拥有了"远程遥控"。但远程意味着**你不在电脑前盯着它**，所以用法和安全都要升级一档。

### 远程派活和本地有什么不同

- **看不到屏幕**：你只能通过它的文字汇报了解进展，所以更要让它"边做边报"。
- **接不了手**：出问题你没法立刻接管，所以**风险操作必须先确认**。
- **得在线**：电脑 / 服务器要开机联网，龙虾才在岗。

### 远程指令的两个好习惯

1. **要它边做边汇报**：
   > 「执行 `<某任务>`，每完成一步用一句话告诉我进度；遇到要删除 / 发送 / 付款的步骤，先停下问我。」
2. **给个"刹车"暗号**：约定一个词（如"停"），看到不对劲随时叫停。

【配图：远程场景示意——人在外用手机，家里 / 云端的电脑里龙虾在执行，箭头表示指令与汇报来回】

> **注意**：远程 + 会动手 = 放大的便利，也是放大的风险。**越是远程、越是无人盯着，越要把"先确认"设成默认。** 3.6 节专门讲怎么给它上"安全锁"。

### 想让它 7×24 在岗？考虑上云

如果你希望"电脑关了它也在干活"，可以把小龙虾部署到云服务器（第 1 章 1.6 提过的云部署）。这样它常驻云端，配合下一节的定时任务，能真正做到"你睡着了它还在干"。云部署属进阶，新手可先用本地电脑跑通，再考虑上云。

## 3.5 让它自动干活：定时任务 + 事件触发

到这里，龙虾还是"你说一句、它干一件"。这一节，让它进化成"**到点自己醒、遇事自己动**"。

### 两种自动化：定时 与 触发

- **定时任务（按时间）**：到某个时间点自动执行。例：每天 8 点出简报。
- **事件触发（按条件）**：满足某条件就自动执行。例：收到老板邮件就提醒你。

（配置入口与写法以官方文档为准。）

### 把第 2 章的案例升级成全自动

还记得第 2 章案例 4 的"每日简报"和案例 7 的"下班收尾"吗？当时还得你手动喊一嗓子。现在给它们装上自动开关：

**自动简报（定时）**
> 「设一个每天早上 8:00 的定时任务：去 `<网站A>`、`<网站B>` 抓 `<主题>` 最新 5 条，去重排序，写成 300 字简报发我微信。」

**自动收尾（定时 + 确认）**
> 「每个工作日 18:30 执行'下班收尾'流程；其中给老板发日报这一步，**发送前先发我确认**。」

**邮件触发（事件）**
> 「以后只要收到来自 `<老板邮箱>` 的邮件，立刻用一句话摘要推送到我微信。」

> **提示**：自动化的精髓，是"把你重复做的固定流程交出去"。先观察自己一周里哪些动作天天重复，再把它们一个个变成定时 / 触发任务。

> **避坑**：别一上来设一堆高频自动任务。① 会烧 token（第 1 章 1.8 的省钱意识别忘）；② 抓取类任务高频会骚扰目标网站。先设 1 个，跑顺了再加。

### 自动化的"安全开关"

自动任务最危险的地方，是它在**你没看着**的时候执行。所以给自动任务定三条铁律（详见 3.6）：

1. 涉及发送 / 付款 / 删除的，**保留人工确认**，别全自动。
2. 给任务设**范围和上限**（只动某文件夹、金额封顶等）。
3. 让它把每次自动执行**记进日志**，你能回查。

## 3.6 无人值守下的安全：把"放养"关进笼子

放养不等于放任。这一章给了龙虾"远程 + 自动"两件大杀器，本节就给它配一套"笼子"。这是本章**最重要**的部分。

### 为什么这一章的安全格外重要

第 2 章我们讲过：会动手 = 有风险，外部内容可能"污染指令"（提示注入）。到了本章，风险被双重放大：

- **远程**：你不在现场，出事没法立刻接管。
- **自动**：它在你没盯着时主动执行，错误可能悄悄累积。

所以，越是远程自动，越要把笼子扎紧。

### 给放养龙虾的六道安全锁

1. **只开一扇门**：聊天入口先接一个，别图多；每个入口都做"仅本人可遥控"绑定。
2. **守好所有钥匙**：Bot Token、API Key、微信授权——按第 1 章 1.8 红线保管，绝不外泄，定期轮换。
3. **危险动作必确认**：发送、付款、删除、群发，一律"先列清单 → 等我 OK → 再执行"，自动任务也不例外。
4. **给任务划边界**：限定它只动哪个文件夹、只发给哪些人、金额 / 数量封顶，别给"无限授权"。
5. **留好审计日志**：让它记录每次（尤其是自动 / 远程）都做了什么，定期回看（日志位置以官方为准）。
6. **留个紧急刹车**：约定停手暗号；事先弄清怎么快速停掉龙虾、断开入口、吊销钥匙。

【配图：放养安全"六道锁"清单图——仅本人 / 守钥匙 / 必确认 / 划边界 / 留日志 / 急刹车】

### 哪些活，远程自动场景下尤其别交

在第 2 章"别交给它"清单的基础上，远程自动场景再加一句提醒：

> **注意**：**任何"做错了无法挽回、且你当时又不在场"的事，都不要设成全自动。** 比如自动清空文件夹、自动批量发邮件、自动付款。便利诱人，但一次翻车可能让你后悔很久。把它们留成"半自动（先确认）"，是最划算的折中。

## 3.7 本章小结 + 实操练习

这一章，你把小龙虾从"电脑前的助手"升级成了"随时随地的远程自动助理"：

- 看懂了它能接哪些聊天入口、自己该选哪个；
- 手把手接通了 Telegram / 微信 QClaw，学会了远程派活的好习惯；
- 用定时与触发，把第 2 章的简报、收尾、邮件提醒升级成了全自动；
- 最重要的是，给"放养"扎好了**六道安全锁**。

到这里，一只"能装、能用、能放养"的成熟龙虾就养成了。

### 留给你的实操练习

1. **（入门）** 把龙虾接到你最常用的一个聊天工具，完成"仅本人遥控"绑定，并发一条任务验证。
2. **（入门）** 用手机远程让它做一件第 2 章学过的小事（如清收件箱），要求它"边做边汇报"。
3. **（进阶）** 把"每日简报"设成每天定时自动执行，连续观察三天并按需调整。
4. **（进阶）** 设一个事件触发任务（如收到某人邮件就提醒你）。
5. **（安全）** 给上面所有自动 / 远程任务过一遍"六道锁"，至少落实"危险动作必确认"和"留审计日志"两条；并演练一次"紧急刹车"——把龙虾快速停掉再恢复。

> **提示**：练习 5 不是可选项。**把放养的笼子先扎好，你才能安心享受放养的自由。**
