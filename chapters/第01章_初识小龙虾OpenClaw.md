## 1.1 引子：那些你不想再重复做的事

每天早上打开电脑，你大概都会经历这样一段"开机仪式"：

- 把十几封邮件挨个点开，删掉广告，把重要的标个星；
- 打开三四个网页，复制一些数据，粘进一张表格；
- 给团队发一条几乎一模一样的日报，只改了日期和数字；
- 想起来还要把昨天下载的一堆文件重命名、归档……

这些事都不难，难的是**它们每天都来一遍**。它们不需要你的智慧，只需要你的时间。

那么问题来了：**能不能有个助手，你用大白话跟它说一句话，它就替你把这些事一条龙做完？**

注意，我说的不是"帮你写一段建议"的聊天机器人，而是真的会**打开浏览器、点开邮箱、动手操作你电脑**的助手。这正是本书的主角——**OpenClaw**，江湖人称"**小龙虾**"——想为你做到的事。

> **提示**：如果你以前用过 ChatGPT 这类工具，你会发现小龙虾是一种"更进一步"的东西。ChatGPT 像一个很会出主意的顾问，而小龙虾更像一个会自己动手干活的实习生。两者的差别，我们在 1.3 节会专门掰开讲。

这一章，我们的目标很简单：**带你认识它、把它装到自己的电脑上、并完成第一次"打招呼"**。哪怕你完全不懂命令行、没听过 Node.js、不知道 API Key 是什么，也没关系——我会一步步带你走。

## 1.2 小龙虾到底是什么

### 一句话定义

> **OpenClaw 是一款开源、免费、可以装在你自己电脑上的"自主型"AI 助手（AI Agent）。**

把这句话里的几个关键词拆开，你就懂了它的全部性格。但在拆之前，先说说它那个可爱的外号。

### 为什么叫"小龙虾"

OpenClaw 里的 **Claw** 是"钳子、爪子"的意思。带着一对大钳子、还挺接地气的形象是什么？没错，小龙虾。于是中文社区就亲切地管它叫"**小龙虾**"，把"装好它"戏称为"**养龙虾**"。本书后面"小龙虾"和"OpenClaw"会换着用，指的都是同一个东西。

### 它的三个关键词：开源、本地、自主

**① 开源、免费**
它的代码是公开的，任何人都能看、能改、能免费用。这意味着没有"会员费"，也意味着全世界的开发者都在帮它变得更好。（截至 2026 年初，它在开源社区 GitHub 上已经积累了**数十万颗 star**，热度极高。具体数字 `<以官方仓库最新数据为准>`。）

**② 本地部署**
它主要**跑在你自己的电脑上**，而不是某个遥远的云端服务器里。你的文件、你的操作，原则上都在你自己手里。（当然它也支持部署到云服务器，我们 1.6 节会讲。）

**③ 自主（会动手）**
这是它和普通聊天机器人最大的区别。你给它一个任务，它能**自己拆解步骤、自己调用工具、自己一步步把活干完**，而不是只丢给你一段文字让你自己去做。

> **提示**：你可以把这三个词记成一句话——"**一只装在你电脑里、不要钱、还会自己干活的 AI 龙虾**"。

### 它的"前世今生"：一段三个月改了两次名的历史

你在网上搜资料时，可能会撞见几个不同的名字，别懵，它们其实是同一个项目：

| 时间 | 名字 | 备注 |
|---|---|---|
| 2025 年 11 月 | **Warelay** | 首次发布时的名字 |
| 2026 年 1 月 27 日 | **Moltbot** | 因 Anthropic 提出商标投诉而改名 |
| 三天后 | **OpenClaw** | 作者嫌 Moltbot"念着不顺口"，定为现名 |

> **注意**：因为改名时间很近，网上很多老教程还在用旧名字（Warelay / Moltbot）。如果你看到这些词，把它当成"小龙虾的曾用名"就行，内容多数仍可参考，但**命令和下载地址一定要以现在的官方文档为准**。

## 1.3 它和 ChatGPT 有什么不同：会"动嘴"还是会"动手"

这是新手最容易混淆的一点，我们用一张表说清楚：

| 对比项 | 普通聊天机器人（如 ChatGPT 网页版） | 小龙虾（OpenClaw） |
|---|---|---|
| 本质 | 会"动嘴"的顾问 | 会"动手"的助手 |
| 你问"帮我回封邮件" | 给你一段**邮件文案**，你自己去粘贴发送 | 直接**打开邮箱、写好、发出去** |
| 能不能操作你的电脑 | 不能 | 能（在你授权范围内） |
| 能不能上网查实时信息并处理 | 受限 | 能打开网页、抓取、整理 |
| 任务有很多步怎么办 | 你得自己一步步喂给它 | 它**自己拆步骤**，连着做完 |
| 跑在哪里 | 别人的云服务器 | 你自己的电脑（也可上云） |
| 收费 | 多为订阅制 | 开源免费（但大模型可能产生费用，见 1.8 节） |

一句话总结：

> **ChatGPT 告诉你"该怎么做"，小龙虾直接帮你"把它做了"。**

正因为它真的能动你的电脑，所以**权力越大、责任越大**——安全问题我们会在 1.5 节和第 2 章反复强调。

## 1.4 小龙虾的"身体构造"：它是怎么干活的

要装好、用好它，你不需要懂它的源代码，但最好对它的"身体构造"有个画面感。它其实由四个部分配合工作：

1. **本体（本地程序）**：装在你电脑上的小龙虾主程序，是整个系统的"身体"和"指挥中心"。
2. **大脑（大模型）**：它本身不"思考"，思考外包给一个大语言模型（比如 Anthropic、OpenAI、Gemini、智谱、Moonshot、DeepSeek 等，任选其一）。你要给它接上一个大脑，它才会动脑子。
3. **双手（各种技能 / 工具）**：操作浏览器、控制电脑、读写文件、收发邮件、调用网络接口……这些"动手"的能力，是通过一个个"技能"（Skill）实现的。
4. **嘴巴和耳朵（聊天入口）**：你不用盯着黑乎乎的终端，而是像跟朋友发消息一样，通过聊天工具（如 WhatsApp、Telegram、Discord、Slack；国内可用微信版的 **QClaw**）给它派活、看它汇报。

把它们串起来就是一句话：

> **你在聊天软件里说一句话 → 小龙虾本体收到 → 交给"大脑"想清楚步骤 → 用"双手"在你电脑上一步步执行 → 把结果回复给你。**

【配图：小龙虾工作原理示意图——左侧"你/聊天工具"，中间"OpenClaw 本体"，上方连接"大模型大脑"，右侧连接"电脑/文件/浏览器/网络"四个图标，箭头表示指令与结果的来回流动】

> **提示**：理解了这个结构，你就能预判后面安装时在干什么——装"本体"（1.7 节）、接"大脑"（1.8 节）、装"双手"基础技能（1.9 节）、连"聊天入口"（第 2 章）。每一步都对应它身体的一个部分。

## 1.5 开工前的准备清单

正式动手前，我们像出门前检查"手机、钥匙、钱包"一样，先把几样东西备齐。下面是一份"开工 checklist"，建议你逐项打勾：

**☐ 1. 一台能联网的电脑**
Windows、macOS、Linux 都支持。国内网络下载依赖可能较慢，建议准备好"镜像加速"（很多一键脚本会自动帮你配，见 1.7 节）。

**☐ 2. 运行环境：Node.js**
小龙虾基于 Node.js 运行，需要 **Node.js `<v22 或更高，以官方最新文档为准>`**。

> **提示**：别被"Node.js"吓到。你可以把它理解成"运行这类程序所需要的发动机"，装一次就好。很多一键安装脚本会**自动帮你检测并安装合适版本**，你甚至不用自己管。

**☐ 3. 包管理器与 Git（部分安装方式需要）**
- **npm** 或 **pnpm**：随 Node.js 一起或额外安装的"软件包搬运工"。
- **Git**：如果你打算用"源码安装"，才需要它；用一键脚本或图形化工具通常**不需要**手动装。

**☐ 4. 一个大模型的 API Key（小龙虾的"大脑"）**
你需要从某一家大模型厂商申请一个 **API Key**（可以理解成一把"调用大脑的钥匙"）。Anthropic、OpenAI、Gemini、智谱、Moonshot、DeepSeek 等都可以，任选其一即可。怎么填进去，1.8 节细讲。

> **注意（费用）**：小龙虾本身免费，但**调用大模型可能按用量收费**。请提前了解你所选厂商的计费方式，并设置好用量上限，避免"龙虾很能干，账单也很能涨"。部分厂商或活动提供免费额度，可优先尝试。

**☐ 5. 系统权限**
因为它要"动手"操作你的电脑，安装时通常需要较高权限：
- **Windows**：用**管理员身份**打开 PowerShell。
- **macOS / Linux**：可能需要 **sudo**（管理员密码）。

> **避坑**：看到要管理员/sudo 权限别慌，这对"要操作电脑的工具"是正常的。但也正因如此，**请只从官方渠道下载**安装脚本，不要随便复制来路不明的命令——这是你的第一道安全防线。

**☐ 6. 一点点耐心**
顺利的话十几分钟就能搞定；遇到网络或权限小插曲也别急，1.10 节备好了常见问题排查表。

## 1.6 四条安装路，你该走哪条

小龙虾有多种安装方式，适合不同人群。先看一张"选路表"，对号入座：

| 安装方式 | 适合谁 | 优点 | 代价 |
|---|---|---|---|
| **① 一键安装脚本** | 大多数普通用户 | 自动装环境、配镜像，命令最少 | 需要复制一行命令到终端 |
| **② 图形化 UI 安装工具** | 最怕命令行的小白 | 点点鼠标就行，免依赖烦恼 | 需额外下载一个安装器 |
| **③ 源码安装** | 想折腾、想改代码的进阶用户 | 最灵活、能改 | 步骤最多，需要 Git/Node 基础 |
| **④ 腾讯 QClaw（封装版）** | 想"绑微信、远程操控"的国内用户 | 免手动配环境、微信即可遥控 | 是第三方封装，跟随其自身规则 |

另外还有一个维度——**装在哪**：

- **本地部署**（推荐新手）：装在自己电脑上，所见即所得，方便学习和调试。
- **云部署**（如阿里云等）：装在云服务器上，可以 7×24 小时不关机地替你干活，适合进阶玩法。

> **提示（本书选择）**：为了让你顺利上手，本章后续以**"一键脚本 / 图形化工具 + 本地部署"**为主线讲解。等你熟练了，再去尝试源码或上云会非常轻松。

> **注意**：上面这些安装方式的**具体名称、下载地址、命令**都可能随版本更新而变化，**请以官方最新文档/官方仓库为准**。下一节给出的命令均为"示例结构"，真正执行时请替换成官方提供的最新命令。

## 1.8 接上"大脑"：配置大模型 API

小龙虾本体装好了，但它现在还是个"没接大脑的身体"。这一步给它接上思考能力。

### 第一步：选一家大模型厂商

Anthropic、OpenAI、Gemini、智谱、Moonshot、DeepSeek 等都可以，**任选其一**。选择时主要看三点：

- **你能不能方便地注册并拿到 API Key**；
- **计费是否在你预算内**（有没有免费额度）；
- **网络是否可达**（国内访问某些海外厂商可能需要额外网络条件）。

### 第二步：申请 API Key

到所选厂商的官网，在其"API Keys / 密钥"页面创建一个新的 Key，复制保存好。它通常是一长串字符，形如 `sk-<一长串字符>`（不同厂商格式不同）。

> **注意（安全红线）**：API Key 等于你账户的"取钱密码"。
> - **不要**截图发群、贴进公开网页、提交到公开代码仓库；
> - **不要**写进任何会被分享的文件；
> - 一旦怀疑泄露，立即到厂商后台**吊销并重新生成**。

### 第三步：把 Key 填给小龙虾

按官方文档指引，在小龙虾的**配置文件**或**设置界面**里，填入厂商名与 API Key。配置项的字段名以官方为准，**示例结构**如下（仅示意，勿照抄）：

```json
{
  "provider": "<你选的厂商>",
  "apiKey": "<你的 API Key>",
  "model": "<该厂商的某个模型名，以官方文档为准>"
}
```

### 省钱（省 token）小技巧

调用大模型按"token"（可理解为字数）计费，下面几招能帮你省钱：

- **任务说清楚**：一次把需求讲明白，减少来回返工。
- **挑性价比模型**：日常杂活用便宜的小模型即可，复杂任务再切换强模型。
- **设用量上限**：在厂商后台设置每月封顶额度。
- **善用免费额度**：优先消耗厂商赠送的免费额度。

> **提示**：第 2 章我们会大量派活给它，"省 token"会变成你的肌肉记忆。现在先知道有这回事就够了。

## 1.9 第一次启动：让小龙虾跟你打声招呼

激动人心的时刻到了——让它真正"活"过来。

### 第一步：打开操作界面

启动小龙虾后，按官方提示在浏览器里打开它的本地操作界面，地址**形如**：

```
http://127.0.0.1:<端口>/
```

其中默认端口**形如** `18789`（`<具体端口以官方最新文档为准>`）。`127.0.0.1` 表示"我自己这台电脑"，所以这个界面只有你本机能访问，相对安全。

【配图：浏览器打开 http://127.0.0.1:18789/ 后看到的小龙虾操作界面首页截图】

> **避坑**：如果打不开，常见原因有两个——① 程序还没真正启动成功；② 端口被占用或填错。排查办法见 1.10 节。

### 第二步：安装基础技能（给龙虾装上"双手"）

第一次进入后，通常需要安装几个**基础技能**，它们是小龙虾最常用的"双手"：

- **浏览器操作技能**：让它能开网页、点按钮、填表单。
- **电脑控制技能**：让它能操作你的电脑（开关程序、读写文件等）。
- **记忆技能**：让它能记住你的偏好和上下文，越用越懂你。
- **自动更新技能**：让它能自己保持版本最新。

## 1.10 常见问题排查（FAQ）

| 现象 | 可能原因 | 怎么办 |
|---|---|---|
| 安装脚本报错"找不到 Node / 版本过低" | Node.js 没装好或版本低于要求 | 按官方文档安装 `<v22+>`，或重跑会自动装环境的一键脚本 |
| Windows 提示"禁止运行脚本" | PowerShell 执行策略限制 | 以管理员身份、按**官方指引**调整执行策略后重试 |
| 提示权限不足 / Permission denied | 没用管理员或 sudo | Windows 用管理员运行；macOS/Linux 加 sudo 重试 |
| 下载依赖极慢或失败 | 国内网络访问海外源慢 | 使用会自动配置**国内镜像**的脚本，或按文档手动配镜像 |
| 浏览器打不开操作界面 | 程序未启动成功 / 端口错或被占用 | 确认程序在运行；核对端口；换端口或释放被占端口（以官方文档为准） |
| 接了大模型却不回复 / 报鉴权错误 | API Key 填错、过期或额度用尽 | 核对 Key 是否正确、未过期；检查厂商后台余额与用量上限 |
| 看到 Warelay / Moltbot 字样 | 旧名残留或老教程 | 它们是小龙虾曾用名，内容可参考，但命令以最新官方文档为准 |

> **提示**：排查任何问题的"万能第一步"，都是回到**官方文档**和**官方社区**核对你这一步的最新做法。工具更新很快，官方信息永远比二手教程靠谱。
