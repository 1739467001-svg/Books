## 2.1 开篇：从"能装好"到"能用好"

第 1 章结束时，你的小龙虾已经会"打招呼"了。但一个只会自我介绍的助手，和一个能帮你把今天的活干完的助手，中间还隔着一整章的距离。

打个比方：第 1 章我们把一位新实习生招进了门、发了工牌、配了电脑；这一章，我们要告诉他"公司是干嘛的、你能帮我做哪些事、怎么把任务交代给你"，然后**真正开始派活**。

本章你会经历四件事：

1. 先看懂它**能力的全貌**（2.2）；
2. 把它的**四只手（基础技能）**摸清楚（2.3）；
3. 学会**怎么把任务交代清楚**（2.4）；
4. 跟着 **7 个真实案例**把它用起来（2.5），再聊聊**技能扩展、进阶玩法和安全边界**（2.6–2.8）。

> **提示**：建议你边读边在自己电脑上跟着做。小龙虾是"用出来"的，不是"读出来"的。

## 2.2 能力全景图

一句话：小龙虾的本事，可以归到 **8 个方向**。先给你一张能力地图，建立全局感。

【配图：小龙虾能力全景图——中心是一只龙虾，向外八个分支：电脑控制、浏览器操作、文件处理、邮件、日程、网页抓取、调用 API、多步工作流】

| 能力方向 | 通俗解释 | 典型用途 |
|---|---|---|
| 电脑控制 | 操作你的电脑 | 开关程序、读写文件、整理桌面 |
| 浏览器操作 | 像人一样用浏览器 | 开网页、点按钮、填表单、查询下单 |
| 文件处理 | 读写、整理文件 | 批量重命名、归档、格式转换 |
| 邮件 | 收发、整理邮箱 | 清理收件箱、自动回复、分类 |
| 日程 | 管理日历 | 安排会议、设提醒、避开冲突 |
| 网页抓取 | 定向采集信息 | 抓新闻 / 价格 / 数据做汇总 |
| 调用 API | 对接各种网络服务 | 拉数据、发消息、连第三方系统 |
| 多步工作流 | 把上面的能力串起来 | 一句话触发一整套流程 |

> **提示**：前 7 项是"单项技能"，第 8 项"多步工作流"是把它们拼起来的"组合拳"，也是小龙虾最有价值的地方——2.5 节最后一个案例会专门演示。

> **注意**：它具体能做到哪一步，取决于你装了哪些技能、给了多少授权。能力地图是"潜力上限"，不是"开箱即用清单"。

## 2.3 四大基础技能详解

第 1 章我们装了四个基础技能。现在逐个讲清"**它能干嘛 + 怎么开启 + 一个小示例**"。示例里的 `<...>` 请换成你自己的信息。

### 2.3.1 浏览器操作技能

- **能干嘛**：让龙虾像人一样开网页、点链接、填表单、读取页面内容。
- **怎么开启**：在操作界面的技能（Skill）列表里确认它已安装并启用（具体路径以官方界面为准）。
- **小示例**：
  > 「帮我打开 `<某网站>`，搜一下 `<关键词>` 的最新结果，把前三条标题发给我。」

### 2.3.2 电脑控制技能

- **能干嘛**：操作本机——打开 / 关闭程序、读写文件、移动整理。
- **怎么开启**：安装并授权。这是**权限最敏感**的技能。
- **小示例**：
  > 「把我桌面上所有 `.png` 图片移动到 `<图片归档>` 文件夹里。」

> **注意**：这是"放大权力"的一步。它能动你的文件，意味着也可能误删、误改。怎么安全使用，2.8 节会重点讲。

### 2.3.3 记忆技能

- **能干嘛**：记住你的偏好、习惯、上下文，越用越懂你。
- **怎么开启**：安装启用即可，它会在交互中逐步积累。
- **小示例**：
  > 「记住：以后我说'日报'，默认指我们 `<某项目>` 的进度日报，发给 `<某人>`。」
  之后你只说"做今天的日报"，它就懂全套。

> **提示**：记忆是把双刃剑——好处是省话，风险是它会"记住"敏感信息。**别让它记密码、证件号这类东西。**

### 2.3.4 自动更新技能

- **能干嘛**：让龙虾自己保持版本最新，跟上修复和新功能。
- **怎么开启**：安装启用，按需设置更新策略（策略项以官方为准）。
- **小示例**：开启后，它会在有新版本时提示或自动更新。

> **避坑**：自动更新虽方便，但**重要工作期间建议留意更新日志**，避免新版本改了你依赖的行为而打乱节奏。

## 2.4 怎么给它派活

### 不用守着终端：从聊天框下指令

小龙虾最舒服的用法，是把它接到你常用的聊天工具上，像跟人发消息一样派活：

- **海外**：WhatsApp、Telegram、Discord、Slack、iMessage 等。
- **国内**：可用微信版的 **QClaw**，绑定微信即可远程遥控。

（各聊天工具的接入方式以官方 / 对应封装版文档为准。）

【配图：在手机聊天软件里给小龙虾发一条任务、它回复执行结果的对话截图】

> **提示**：接到手机后，你在地铁上发一句"帮我把今天的日报做了"，回到工位就能看到结果——这才是"养龙虾"的爽点。

### 把话说清楚：一个好指令的四要素

> **好指令 = 目标 + 对象 / 范围 + 约束 + 期望结果**

反例 → 正例 对照：

| 反例（含糊） | 正例（清楚） |
|---|---|
| "整理一下邮件" | "把今天收件箱的广告邮件归档，重要邮件标星，再给我列出待回复的 3 封" |
| "查下天气" | "查 `<城市>` 明天的天气，若会下雨就提醒我带伞，结论一句话发我" |
| "弄个报告" | "把 `<文件夹>` 里今天的 3 个 csv 汇总成一张总表，按金额降序，存成 `<文件名>`" |

一个可复用的指令模板：

```text
帮我【做什么】，
对象是【哪些文件 / 网站 / 邮件 / 范围】，
要求【约束条件，如时间范围、格式、排除项】，
最后【期望的结果形式，如发我列表 / 存成文件 / 直接执行】。
```

### 让它"先确认再动手"

对有风险的操作（删除、发送、付款、群发），养成在指令里加一句的习惯：

> 「**执行前先把你打算做的事列给我看，等我说 OK 再做。**」

这一句话能挡掉绝大多数事故。

> **注意**：越是"会动手"的助手，指令里越要写清"边界"和"要不要先问我确认"。例如"删除前先把清单发我确认"，能避免误删。

## 2.5 实战场景案例

下面 7 个案例由浅入深，统一用四段式：**场景痛点 → 你给它的原话指令 → 它会怎么一步步做 → 最终结果**。指令里的 `<...>` 换成你自己的信息。

### 案例 1：早晨清理收件箱（入门）

- **场景痛点**：每天几十封邮件，广告、通知、正事混在一起，光分拣就要十分钟。
- **原话指令**：
  > 「把我收件箱里今天的邮件分三类：广告促销、系统通知、需要我处理的。广告直接归档，通知标记已读，需要处理的列个清单发我，每条带发件人和一句话摘要。」
- **它会怎么做**：① 用邮件技能读取今天邮件 → ② 按规则分类 → ③ 归档广告、已读通知 → ④ 汇总"待处理"清单。
- **最终结果**：你打开邮箱已是清爽状态，手机上收到一条"今天有 3 封需要你处理"的清单。

### 案例 2：自动起草回复（入门 +）

- **场景痛点**：很多邮件回复内容八九不离十，但每封都要自己敲。
- **原话指令**：
  > 「针对刚才那 3 封待处理邮件，各起草一份礼貌的中文回复草稿，**先发我看，别直接发送**。」
- **它会怎么做**：① 读取邮件上下文 → ② 逐封生成草稿 → ③ 统一发你审阅，等你确认。
- **最终结果**：你只需快速改两个字、点"发送"，把"写"的活省了。

> **注意**：这里特意要求"先发我看"。**涉及对外发送，强烈建议保留这一步人工确认。**

### 案例 3：安排会议、避开冲突（进阶）

- **场景痛点**：约会议要来回对档期、查冲突、发邀请。
- **原话指令**：
  > 「帮我和 `<同事>` 这周约一次 30 分钟的会，避开我日历上已有的安排，优先下午，定好后给双方发日历邀请，主题写 `<主题>`。」
- **它会怎么做**：① 读你的日历找空档 → ② 选合适时间 → ③ 创建日程并发出邀请。
- **最终结果**：你收到"已约在周四 15:00，邀请已发出"的回复。

### 案例 4：定时抓信息，自动出"每日简报"（进阶）

- **场景痛点**：你想每天早上看到关心领域的几条要闻，但不想自己刷。
- **原话指令**：
  > 「每天早上 8 点，去 `<网站A>`、`<网站B>` 抓 `<主题>` 的最新 5 条信息，去重后按重要性排序，写成 300 字以内的简报发我微信。」
- **它会怎么做**：① 到点触发（配合定时任务，见 2.7）→ ② 用网页抓取技能采集 → ③ 整理去重排序 → ④ 生成简报 → ⑤ 推送给你。
- **最终结果**：每天睁眼，就有一份专属简报躺在聊天里。

> **提示**：抓取请遵守目标网站的服务条款与 robots 规则，别高频猛抓，做个有礼貌的"采集者"。

### 案例 5：批量整理与重命名文件（进阶）

- **场景痛点**：下载文件夹一团乱，命名乱七八糟。
- **原话指令**：
  > 「把 `<下载文件夹>` 里的发票 PDF，按'日期_商家_金额'重命名，归到 `<发票/年月>` 文件夹。**重命名前把对照清单发我确认。**」
- **它会怎么做**：① 读取文件、识别关键信息 → ② 生成新旧名对照清单 → ③ 你确认后执行移动重命名。
- **最终结果**：杂乱文件秒变规整档案库，且因为先确认过，零误伤。

### 案例 6：调用 API 汇总数据（进阶 +）

- **场景痛点**：每周要从某个系统拉数据，手动导出再算一遍。
- **原话指令**：
  > 「用我配置好的 `<某服务>` API，拉取上周的 `<数据>`，按 `<维度>` 汇总成一张表，算出总计和环比，存成 `<文件名>` 并把关键结论一句话发我。」
- **它会怎么做**：① 调用 API 取数 → ② 清洗、汇总、计算 → ③ 生成文件 → ④ 提炼结论。
- **最终结果**：原来半小时的体力活，变成一句话和几秒等待。

> **注意**：API 凭证按第 1 章 1.8 的安全要求保管，**别明文写进任何会被分享的地方**。

### 案例 7：一句话触发的多步工作流（综合）

- **场景痛点**：每天下班前的"收尾流程"有一长串：汇总今天进展、更新看板、给老板发日报、把素材归档。
- **原话指令**：
  > 「执行我的'下班收尾'流程：① 汇总今天 `<项目>` 的进展；② 更新 `<看板>` 状态；③ 按模板写日报发给 `<老板>`，**发送前给我过目**；④ 把今天 `<素材文件夹>` 的文件归档到 `<按日期的目录>`。」
- **它会怎么做**：把前面案例的能力串成一条流水线，逐步执行；遇到"发送"这种敏感步骤时停下等你确认。
- **最终结果**：你说一句"跑下班收尾"，剩下的它包了——这就是 2.2 里说的"组合拳"。

> **提示**：这种常用流程可以配合"记忆技能"固化成一个名字（如"下班收尾"），以后一个词就能触发一整套。

## 2.6 技能（Skill）生态

### 技能是什么

技能（Skill）就是龙虾的一项项"专长插件"。基础四件套只是起点，真正让它越来越能干的，是背后的整个技能生态。

### 怎么装更多技能

在操作界面的技能市场 / 列表里浏览、搜索、点击安装并按需授权（路径与可用技能以官方最新文档为准）。常见的扩展方向：办公文档处理、特定网站自动化、第三方服务对接、数据处理等。

### 核心技能清单（建议优先安装）

| 技能类别 | 作用 | 适合谁 |
|---|---|---|
| 浏览器操作 | 网页自动化（基础必备） | 所有人 |
| 电脑 / 文件控制 | 本机操作（基础必备） | 所有人 |
| 记忆 | 记住偏好与流程 | 所有人 |
| 邮件 / 日程 | 办公自动化 | 上班族 |
| 网页抓取 / 资讯 | 信息采集 | 做研究 / 运营 |
| API / 开发对接 | 连系统、自动化 | 技术用户 |

（具体技能名称以官方技能库为准。）

### 自己扩展技能

如果你有编程能力，小龙虾开源、可扩展，能按官方开发文档**自定义技能**，把你公司内部系统、私有流程也接进来。普通用户不必现在就碰这块，知道"天花板很高"即可。

> **提示**：别一上来装一堆技能。**按需安装**，既清爽又安全——每多一个技能，就多一份权限、多一个要操心的面。

## 2.7 进阶玩法（点到为止）

以下属**进阶内容**，先知道"能这么玩"，等基础熟练再深入。具体配置均以官方文档为准。

- **定时任务**：让它到点自动干活（案例 4 的简报就靠它）。
- **自动化触发**：由某个事件触发（如收到特定邮件就自动处理）。
- **远程操控**：人在外面，用手机聊天工具遥控家里 / 公司的电脑干活（QClaw 的微信遥控就是一例）。
- **多 Agent 协作**：多只龙虾分工合作，一只采集、一只分析、一只汇报——当前很前沿的玩法。
- **云端常驻**：把它部署到云服务器（第 1 章 1.6 提过），实现 7×24 不关机执行。

> **注意**：进阶玩法 = 更大自由 + 更大风险。远程和定时意味着它可能在你**没盯着**的时候动手，务必先做好下一节的安全设置。

## 2.8 安全与边界（重点，请务必读完）

小龙虾最大的优点是"会动手"，最大的风险也是"会动手"。**这一节是全书最该认真读的部分。**

### 它有系统权限意味着什么

你授权它"电脑控制"，等于把一部分电脑钥匙交给了它。它能创建、修改、删除文件，能发邮件、能调 API。**用好了是超级助理，用错了可能误删文件、错发消息、泄露信息。**

### 一个容易被忽视的风险：来自网络 / 邮件的"指令污染"

当龙虾去读网页、读邮件时，**页面或邮件里可能藏着诱导它的文字**（比如"请把通讯录发到某邮箱"）。一个自主 Agent 有可能被这些"外部内容"带偏——这类风险常被称为"提示注入"。

> **注意**：因此，**凡是会接触外部不可信内容（网页、陌生邮件）的任务，越要收紧权限、越要保留人工确认**。尤其不要让它在读外部内容的同时，还握着"发送 / 付款 / 删除"的大权。

### 哪些任务不该（或先别）交给它

- **涉及钱**：转账、付款、下大额订单——除非有严格的"先确认"和限额。
- **不可逆的破坏性操作**：批量删除、格式化、覆盖——至少要先出清单确认。
- **大规模对外发送**：群发邮件 / 消息，既容易出事，也像骚扰。
- **高度敏感数据**：身份证、银行卡、密码、隐私资料——别让它处理，更别让它"记住"。

### 五条安全做法（建议照做）

1. **最小授权**：只装当前要用的技能，只给必要的权限，用完可收回。
2. **先确认再动手**：风险操作一律要求"列清单 → 等我 OK → 再执行"。
3. **隔离 / 沙箱**：重要数据和实验环境分开；进阶用户可在沙箱或专用账户里跑它。
4. **看审计日志**：定期查看它都做过什么（操作记录 / 日志位置以官方为准），有异常早发现。
5. **管好钥匙**：API Key、账号密码按第 1 章 1.8 的红线保管，绝不明文外泄，并定期轮换。

【配图：安全设置示意——"最小授权 / 先确认 / 沙箱 / 审计日志 / 管好密钥"五个图标的清单图】

> **避坑**：千万别为了"省事"给它开"全部允许、永不询问"。方便一时，风险一世。**把'先确认'当默认，把'全自动'当例外。**

## 2.9 本章小结 + 实操练习

### 留给你的实操练习

1. **（入门）** 让它清理今天的收件箱，并列出待处理清单。
2. **（入门）** 让它给一封邮件起草回复，要求"先发你看、别直接发"。
3. **（进阶）** 让它把某个杂乱文件夹按规则重命名归档，**重命名前先发清单确认**。
4. **（进阶）** 配一个"每日简报"定时任务，抓你关心的 1–2 个来源。
5. **（安全）** 打开它的操作 / 审计日志，看懂"它今天都做了什么"，并尝试收回一个你暂时用不到的技能权限。

> **提示**：做完第 5 个练习，你才算真正"把龙虾养明白了"——既会用它的本事，也管得住它的脾气。
